# Лабораторная работа №1: регрессия

Ноутбук: [lab01_solution.ipynb](./lab01_solution.ipynb).

## Запуск

1. Откройте репозиторий в VS Code или Jupyter и откройте `regression/lab01_solution.ipynb`.
2. Установите зависимости: `pip install numpy pandas matplotlib seaborn scikit-learn ipykernel`.
3. Выберите Python kernel и запустите **Run All**. CSV уже находятся в `regression/data/`.
4. Посмотрите на `cv_table` и `test_table`. Скрытый leaderboard преподавателя требует отдельной проверки.

**Метрика:** RMSE (чем меньше, тем лучше); порог скрытого теста — строго меньше 0.70. Дополнительная метрика: MAE.

**Важно:** исходное ТЗ не уточняет красное или белое вино, поэтому объединены обе таблицы UCI Wine Quality с признаком `is_red`. Модели и гиперпараметры отбираются по CV на обучающей выборке; test используется однократно в финале. В ноутбуке намеренно отсутствуют заранее вписанные значения метрик: числа появляются только после фактического выполнения на данных.

Источник: https://archive.ics.uci.edu/dataset/186/wine+quality
